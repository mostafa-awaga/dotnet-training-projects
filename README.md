# .NET Training Projects

A collection of .NET learning projects and exercises covering C#, APIs, database work, and a ShopEasy project.

## Repository Contents

- `C#` — C# practice and exercises.
- `API` — API-related practice work.
- `Database` — Database exercises and practice files.
- `ShopEasy_Project` — ShopEasy .NET project.

## Featured Folder: ShopEasy_Project

Path: [`ShopEasy_Project`](./ShopEasy_Project)

The ShopEasy project contains a .NET solution that can be opened from:

```text
ShopEasy_Project/ShopEasy_Project.slnx
```

## Tech Stack

- C#
- .NET
- ASP.NET Core concepts
- SQL / Database fundamentals
- Visual Studio

## Run Locally

1. Clone the repository.
2. Open the project or exercise folder you want to review.
3. For ShopEasy, open `ShopEasy_Project/ShopEasy_Project.slnx` in Visual Studio.
4. Restore dependencies and run the project from Visual Studio or the .NET CLI.
